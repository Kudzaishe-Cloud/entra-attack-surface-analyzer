# Example Reports

This directory contains sanitized example reports generated by the Entra ID Attack Surface Analyzer.

## Files

- **example-report.json** — JSON format with structured findings (machine-readable)
- **example-report.csv** — CSV format (Excel/spreadsheet-compatible)

## What the Reports Show

- **12 total findings** from a sample Entra ID environment
- **High severity issues** (2 orphaned applications, 1 weak MFA)
- **Medium severity issues** (9 inactive users)
- **Remediation guidance** for each finding

## Report Format

### JSON Structure
```json
{
  "scan_date": "ISO 8601 timestamp",
  "total_findings": number,
  "findings_by_severity": {
    "CRITICAL": count,
    "HIGH": count,
    "MEDIUM": count,
    "LOW": count
  },
  "findings": [
    {
      "type": "check type",
      "severity": "severity level",
      "resource": "affected resource",
      "description": "what was found",
      "remediation": "how to fix it"
    }
  ]
}
```

### CSV Structure
Columns: severity, type, resource, description, remediation

## Using the Reports

1. **For Analysis:** Import JSON into your security tools
2. **For Spreadsheets:** Open CSV in Excel/Google Sheets
3. **For Dashboards:** Parse JSON to create custom visualizations
4. **For Automation:** Script against JSON for ticketing/workflows

See [REMEDIATION.md](../docs/REMEDIATION.md) for detailed fixes.
